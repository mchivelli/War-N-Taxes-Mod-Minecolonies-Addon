# Product Overview

**MineColonyTax: War 'N Taxes** is a comprehensive Minecraft Forge mod that extends MineColonies with advanced warfare, taxation, and diplomatic systems.

## Core Features

- **Automated Tax System**: Periodic tax collection from colonies with debt tracking and SDMShop integration
- **War System**: Structured warfare with declaration phases, join mechanics, lives tracking, and victory conditions
- **Raid Mechanics**: Territory-based raids with progressive rewards and automatic termination
- **Entity Raids**: Configurable entity-triggered raids based on proximity thresholds
- **Peace Proposals**: Diplomatic resolution system with reparations and negotiations
- **Colony Permissions**: Universal item interaction permissions for all players
- **Statistics & History**: Comprehensive tracking of wars, raids, and player performance
- **Admin Tools**: Debug commands and server management utilities

## Target Audience

Server administrators and players using MineColonies who want enhanced PvP, economic, and diplomatic gameplay mechanics.

## Key Dependencies

- Minecraft Forge 1.20.1
- MineColonies mod ecosystem (BlockUI, Structurize, Domum Ornamentum)
- SDMShop (optional, for currency integration)
- FTB Teams (for team-based mechanics)
- Recruits mod (for additional combat features)
